# Portafolio — Techunlock

Sitio web de portafolio profesional en un único archivo `index.html` listo para producción.

## Stack

- HTML5 semántico
- Tailwind CSS (CDN)
- Font Awesome 6
- Google Fonts: Inter + JetBrains Mono

## Vista previa

Abre `index.html` en cualquier navegador moderno — sin paso de build.

## Secciones

1. Navbar fijo con glassmorphism
2. Hero con robot mascota animado
3. Sobre mí + métricas
4. Habilidades por categoría
5. Galería de proyectos
6. Formulario de contacto + redes
